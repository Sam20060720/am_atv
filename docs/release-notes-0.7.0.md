# AMATV 0.7.0 更新內容

這版新增手機掃碼登入，也可以在設定切換「經典介面」與「Apple 風格」。以下整理自 v0.6.2 起的更新。

## 下載

| APK | 適用版本 | 字型 |
| --- | --- | --- |
| `AMATV-0.7.0.apk`（標準版） | Android 7 以上 | 電視系統字型 |
| `AMATV-0.7.0-font.apk`（內建字型版） | Android 6 以上 | Noto Sans CJK TC |

兩版皆支援 ARM32 和 ARM64。手機與電視連上同一個 Wi-Fi 後，可以掃 QR Code 登入。也可以直接在電視登入。

## 介面與遙控器

- 預設使用經典介面，切換樣式時音樂會繼續播放。長按選單和歌詞設定也會一起換成所選樣式。
- 修正開啟 App、登入、回首頁或進入歌單時，方向鍵有時無法移動選取項目的問題。從詳情頁返回時會回到原來的卡片。
- 調整導覽列、播放控制與卡片的選取框和間距，讓長按方向鍵時可連續移動。
- 返回鍵逐頁返回。在最外層按返回會詢問是否離開。播放中可選擇離開後繼續播放或停止。

## 登入、首頁與搜尋

- 手機登入和電視登入按鈕並排，可用方向鍵左右切換。登入後會隱藏登入按鈕。
- 首頁和新發現可瀏覽更多推薦、最近播放、排行榜與曲風。
- 「顯示全部」會把歌曲排成列表，專輯和歌單排成封面網格。返回時會回到原本的分類和位置。已列出全部項目的分類會隱藏這個按鈕。
- 可重用或清除搜尋紀錄，並用方向鍵選擇搜尋建議。歌曲、專輯和其他種類各自載入下一頁。搜尋和媒體庫篩選欄關閉鍵盤後，都可以用方向鍵回到清單。

## 媒體庫與歌單

- 可以瀏覽最近加入、歌曲、專輯、藝人和歌單，也可以進入歌單資料夾或返回上層。
- 支援名稱排序、文字篩選和字母跳轉。歌曲與專輯也可按藝人排序。
- 可建立歌單和資料夾。可編輯的歌單支援改名、刪除和調整歌曲順序。資料夾支援改名和移動，空資料夾可以刪除。
- 可取消喜好、從媒體庫移除有對應 Apple Music 目錄項目的歌曲，也可把歌單移到其他資料夾。
- 加入喜好、加入媒體庫、建立歌單或加歌後，選單會顯示結果。如果暫時無法確認，可以重新查詢。
- 加入喜好或歌單時可一併把歌曲加入媒體庫。兩個選項預設關閉。
- 可反轉歌單原有順序，瀏覽和待播清單會一併反轉。手動排過的歌單也按當前順序反轉。
- 播放大型歌單時，可先播已載入的歌曲並接著讀取後面的曲目。隨機播放可先播放抽中的歌曲。歌單中重複加入的歌曲會保留。

## 播放

- 修正首次起播、手動切歌、待播清單接續和背景播放的問題。重新開啟 App 可恢復待播清單和播放位置。
- 新增睡眠計時。可選 15、30、45 或 60 分鐘，也可在目前歌曲、專輯或歌單結束時停止。
- 歌曲資訊會列出演出人員、詞曲作者和製作人員。可從選單前往相關專輯或藝人。
- 可複製或分享 Apple Music 連結。電視可顯示 QR Code，供手機掃描開啟。
- 可由歌曲建立電台。電視有提供相容的等化器時，可從播放選項開啟。
- 播放中、待播清單、搜尋和歌曲列表會在 Apple Music 標為 Explicit 的歌曲旁顯示 E。
- 可選高音質或高效率 AAC。Dolby Atmos 預設關閉，歌曲與裝置都支援時可播放 Atmos 音軌，其餘情況使用 AAC。更改音質會在下一首或重新播放時生效。
- 可從設定的「音樂律動」授權。從背景播放回到播放頁時，App 會記住先前是否已詢問。一般緩衝會顯示較小的提示。

## 歌詞

- 設定的「歌詞同步」可用左側「−5 毫秒」提前歌詞，或用右側「+5 毫秒」延後。中間顯示目前偏移量。
- 翻譯和發音可分別關閉、跟隨語言設定或指定語言，也可調整文字大小。
- 修正歌詞或歌詞設定一直顯示載入中的情況，並依帳號地區和語言取得歌詞。
- 減少原文、翻譯和發音顯示同一段文字。歌曲本身重唱的段落會保留。
- 暫停時選取有時間標記的歌詞，會從該句開始播放。歌曲還在載入時會記住所選位置。
- 跳轉後會選取播放進度條。另修正靜態歌詞捲動和切歌後的按鍵操作。

## 廣播與封面

- 廣播和節目會顯示正在播放的歌曲、封面和音樂律動。重新開啟單集可接續先前進度。
- 廣播使用登入帳號的地區。重新播放電台時會更新曲名與封面。
- 修正部分電台停住後一直顯示緩衝，或快速按播放和暫停後畫面與聲音不同步的問題。播放中的電台斷線時會嘗試重連。
- 首頁捲回看過的卡片時會重用已載入的封面，減少封面閃爍和重抓圖片。歌詞只在顯示時更新動畫。
- 修正靜態與動態封面切換時，卡片比例和標題換行改變的問題。設定可關閉動態封面。
- 連線驗證失敗時，App 會提示檢查電視的日期、時間與網路。

無損與高解析度無損目前無法選取。Atmos 的實際輸出取決於電視與音響。
