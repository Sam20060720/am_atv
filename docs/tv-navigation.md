# 電視遙控器

| 畫面 | 方向鍵 | 確認與返回 |
| --- | --- | --- |
| 首頁、新發現、廣播 | 左右移動同一列，上下切換列 | 確認開啟卡片。從詳情或「顯示全部」返回會回到原來的項目。 |
| 搜尋 | 往下從輸入框移到建議、搜尋範圍、分類和結果 | 按確認輸入或開啟結果。鍵盤開啟時，返回會先收起鍵盤。 |
| 媒體庫 | 上下選分類，向右進入該分類。歌曲列表向左回分類。 | 確認開啟項目或播放。進入資料夾後，返回會回到上一層。 |
| 專輯、歌單 | 上下移動歌曲，從第一首向上回操作列。左右切換播放和隨機播放。 | 確認執行所選操作。返回回到開啟詳情前選的卡片。 |
| 播放頁 | 控制列左右選按鈕，向上到可用的進度條。進度條左右預覽前後 5 秒。 | 確認跳到預覽位置。返回可取消預覽，或收起播放控制。 |

在歌曲或封面上長按確認，可開啟該項目的操作選單。返回會關閉選單，並回到原來的項目。

從設定可切換經典和 Apple 介面。經典介面使用上方導覽列。Apple 介面展開側欄後，向右可回到目前頁面，保留所選項目與捲動位置。在側欄確認目前分頁，會關閉詳情並回到該分頁頂端。

## 修改按鍵操作時的檢查

- 進入分類後，載入中的畫面仍應讓人離開。若使用者已移開選取項目，延遲回應應只更新清單。
- 分頁原本停在「載入更多」時，新增項目後應選到第一筆新資料。原本停在卡片時，繼續選在該卡片。
- 逐層返回專輯、歌單或藝人頁時，確認每一層都回到原來選的項目。切換分頁後再回來，也應保留原先的位置。
- 用方向鍵選一個項目並開啟，返回後再按一次確認。兩次應開啟同一個項目。測試指令見 [測試指南](testing.md)。
