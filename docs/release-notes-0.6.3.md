# AMATV 0.6.3 更新內容

## 介面與遙控器操作

- 新增「經典」與「Apple」兩種介面，可在設定切換；預設使用經典介面。
- 改善首次開啟、登入後、返回首頁及進入歌單時的焦點，減少方向鍵沒有反應、需要按返回才能繼續操作的情況。
- 改善長按選單、歌詞選單與頁面之間的遙控器操作，並調整經典介面的焦點框與間距。
- 返回鍵會逐層返回，回到最外層才詢問是否離開。
- 播放時離開 App，可選擇「離開並繼續播放」或「離開並停止播放」。

## 首頁、搜尋與歌單

- 改善首頁捲動與封面切換的流暢度，減少動態封面首次載入、捲回卡片時的閃爍。
- 整理「顯示全部」頁面的內容與操作，完整的小分類不再提供重複內容的入口。
- 改善搜尋、分類篩選與輸入框的遙控器操作。
- 新增歌單反轉設定，可將原本排在後面的歌曲放到前面瀏覽與播放，待播順序也會一致調整。
- 改善大型歌單的接續播放與隨機播放等待體驗。
- 已登入時隱藏手機 QR 登入按鈕。

## 播放與歌詞

- 改善起播、手動切歌、背景播放及重新開啟 App 後的播放銜接。
- 改善背景播放後返回「播放中」頁面時，重複詢問音訊權限造成的畫面閃動；設定新增「音樂律動」授權入口。
- 暫停時選取歌詞段落，會跳到該段並開始播放；歌曲仍在載入時也會保留選取位置。
- 整理翻譯與發音的分層選單，減少與原文或彼此重複的歌詞文字。
- explicit 歌曲在歌名旁顯示 E 標記，涵蓋播放中、待播清單、搜尋與歌曲列表。
- 新增高音質／高效率 AAC 選項，以及預設關閉的 Dolby Atmos 開關。變更會在下一首或重新播放時生效；Atmos 依歌曲與裝置支援情況使用，無法使用時回到 AAC。

## 廣播與連線

- 廣播使用登入帳號的地區，重新播放時更新目前歌曲與封面資訊。
- 修正部分電台停止更新後一直停在緩衝中的情況，並改善播放、暫停快速切換時的狀態。
- 連線驗證失敗時會提示檢查裝置日期、時間與網路，方便辨識起播失敗的原因。

目前不支援無損與高解析度無損播放。
